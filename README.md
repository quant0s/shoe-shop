# ShoeShop — система оформления заказов обуви

Учебный проект: десктопное приложение для просмотра каталога обуви и оформления заказов в рамках демонстрационного экзамена.

## Возможности
- Просмотр каталога моделей обуви с отображением цены, скидки и количества на складе;
- Фильтрация по производителю/категории, сортировка по стоимости и полнотекстовый поиск товаров;
- Оформление заказа авторизованным клиентом с автоматическим расчётом итоговой скидки;
- Панель управления товарами и заказами для менеджера и администратора;
- Автоматизированное тестирование операций с заказами.

## Требования
- Python 3.10+ (рекомендуется Python 3.11 / 3.13)
- СУБД PostgreSQL 14+
- Библиотеки из файла `requirements.txt` (PySide6, psycopg, pillow, SQLAlchemy)

## Установка и запуск
1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/quant0s/shoe-shop.git
   cd shoe-shop
   ```
2. Создать виртуальное окружение и активировать его:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Создать базу данных PostgreSQL и импортировать схему:
   ```bash
   psql -U postgres -d shoe_shop -f database/shoe_store.sql
   ```
4. Скопировать шаблон настроек и указать параметры подключения:
   ```bash
   copy config.ini.example config.ini
   ```
   Отредактируйте `config.ini`, указав актуальный пароль пользователя PostgreSQL.
5. Запустить приложение:
   ```bash
   python main.py
   ```

## Структура репозитория
- `main.py` — главная точка входа в приложение;
- `catalog.py` — контроллер каталога товаров, авторизации и управления заказами;
- `resources/` — графические ресурсы, иконки и изображения товаров;
- `database/` — SQL-скрипт создания и наполнения базы данных `shoe_store.sql`;
- `docs/` — сопроводительная документация и ER-диаграмма базы данных (`er_diagram.pdf`);
- `config.ini.example` — шаблон конфигурационного файла подключения к БД.

### Описание схемы базы данных (ER-диаграмма)
В каталоге `docs/er_diagram.pdf` представлена концептуальная схема реляционной базы данных «Магазин обуви». Схема включает 5 основных таблиц:
- `users` — учетные записи пользователей системы (клиенты, менеджеры, администраторы);
- `items` — каталог товаров (наименование, артикул, стоимость, скидка, остаток на складе);
- `orders` — заголовки заказов с датами создания, доставки и пунктом выдачи;
- `orders_items` — состав заказов (связь M:N между заказами и товарами с указанием количества);
- `pickup_points` — адреса пунктов выдачи заказов.
